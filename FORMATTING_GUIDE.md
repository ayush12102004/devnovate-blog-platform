# PROJECT REPORT FORMATTING GUIDE

## Step-by-Step Instructions for Creating Final Report

### Step 1: Convert Markdown to Word Document

1. Open the `PROJECT_REPORT.md` file
2. Copy all content
3. Open Microsoft Word (or Google Docs)
4. Paste the content
5. Save as `.docx` format

### Step 2: Apply Formatting Guidelines

#### 2.1. Page Setup
- Go to **Layout** → **Margins** → **Custom Margins**
- Set:
  - **Left:** 3.8 cm
  - **Right:** 2.5 cm
  - **Top:** 2.5 cm
  - **Bottom:** 2.5 cm
- **Paper Size:** A4
- **Orientation:** Portrait

#### 2.2. Font Settings
- Select all text (Ctrl+A)
- Set font to **Times New Roman**
- Set font size to **11pt**
- Set line spacing to **1.5** (Line spacing options → 1.5)
- Set alignment to **Justify** (Ctrl+J)

#### 2.3. Heading Formatting

**Chapter Titles (e.g., "CHAPTER 1: INTRODUCTION"):**
- Font: Times New Roman
- Size: 16pt
- Style: Bold
- Alignment: Left
- Add 24pt line space before heading

**First Level Headings (e.g., "1.1. Overview of Blogging Platforms"):**
- Font: Times New Roman
- Size: 14pt
- Style: Bold
- Alignment: Left
- Capitalize first letter of each major word

**Second Level Headings (e.g., "4.2.1. User Model"):**
- Font: Times New Roman
- Size: 12pt
- Style: Bold
- Alignment: Left

**Third Level Headings:**
- Font: Times New Roman
- Size: 12pt
- Style: Bold Italic
- Alignment: Left

#### 2.4. Page Numbers
- Go to **Insert** → **Page Number** → **Bottom of Page** → **Plain Number 3** (bottom right)
- Start page numbering from the first page of main content (after preliminary pages)

#### 2.5. Code Blocks and Algorithms
- Select code snippets
- Set font to **Courier New** or **CMTT10** (typewriter font)
- Size: 10pt or 11pt
- Use single spacing for code blocks
- Indent algorithm steps appropriately

#### 2.6. Tables
- Table captions should be **above** the table
- Caption format: "Table X: [Description]"
- Use consistent table formatting
- Ensure tables fit within margins

#### 2.7. Figures
- Figure captions should be **below** the figure
- Caption format: "Figure X: [Description]"
- Ensure figures are clear and readable
- Scale figures to fit within margins

#### 2.8. Abstract
- Set font size to **11pt**
- Add two blank lines (10pt spacing) before "ABSTRACT" title
- Add two blank lines (10pt spacing) after "ABSTRACT" title
- Abstract should be 150-300 words

### Step 3: Preliminary Pages Setup

#### 3.1. Outer Title Page (Hard Bind)
- This will be created separately by the binding service
- Brown background with silver text
- Include: Project title, student names, institution, year

#### 3.2. Inner Title Page
- White paper
- Center alignment
- Include all title page information

#### 3.3. Declaration Page
- Left align student signatures
- Add date and place fields
- Leave space for signatures

#### 3.4. Approval Certificate
- Include all required signatures:
  - Project Guide
  - Project Coordinator
  - Head of Department
- Leave space for signatures and dates

#### 3.5. Certificate by Examiner
- Include Internal and External Examiner signatures
- Leave space for signatures and dates

### Step 4: Table of Contents

1. After formatting all headings, go to **References** → **Table of Contents**
2. Select **Automatic Table 1** or **Custom Table of Contents**
3. Update page numbers
4. Ensure all sections are included with correct page numbers

### Step 5: Lists Setup

#### 5.1. List of Tables
- Create a new page after Table of Contents
- List all tables with page numbers
- Format: "Table X: [Description] ................ Page Number"

#### 5.2. List of Figures
- Create a new page after List of Tables
- List all figures with page numbers
- Format: "Figure X: [Description] ................ Page Number"

#### 5.3. List of Abbreviations
- Create a new page after List of Figures
- Format as two-column table or list
- Left column: Abbreviation
- Right column: Full form

### Step 6: Main Content Formatting

1. Ensure all text is justified (fills to right margin)
2. Check for proper hyphenation (Word can auto-hyphenate)
3. Verify heading hierarchy is consistent
4. Ensure proper spacing between sections
5. Check that code blocks use typewriter font

### Step 7: References Formatting

- Use numbered references in square brackets: [1], [2], [3]
- Format references consistently
- Include all required information:
  - Author names
  - Publication year
  - Title
  - Source/URL
  - Access date (for online sources)

### Step 9: Print Preparation

1. **Print Settings:**
   - Use high-resolution printer (300 dpi minimum)
   - Print on one side only
   - Use A4 size bond paper
   - Check print quality before final printing

2. **Binding:**
   - Prepare 3 copies:
     - One for university/college (with CD/DVD containing soft copy)
     - One for supervisor
     - One for candidate
   - Outer cover: Hard bind with brown background and silver text
   - Inner title page: White paper

3. **CD/DVD Contents:**
   - Project report (PDF and Word format)
   - Presentation slides
   - Source code (complete project folder)
   - README file with setup instructions

### Step 10: Plagiarism Check

1. Use a plagiarism detection tool (Turnitin, Grammarly, etc.)
2. Generate plagiarism report
3. Ensure similarity percentage is acceptable (typically <10-15%)
4. Address any flagged content
5. Add plagiarism report to the document

## Quick Formatting Shortcuts

- **Select All:** Ctrl+A
- **Justify Text:** Ctrl+J
- **Bold:** Ctrl+B
- **Italic:** Ctrl+I
- **Font Size:** Ctrl+Shift+P
- **Line Spacing:** Ctrl+1 (single), Ctrl+5 (1.5), Ctrl+2 (double)

## Common Issues and Solutions

### Issue: Text not filling to right margin
**Solution:** Enable hyphenation: **Layout** → **Hyphenation** → **Automatic**

### Issue: Page numbers not appearing
**Solution:** Check if headers/footers are enabled and page numbers are inserted correctly

### Issue: Headings not formatting correctly
**Solution:** Use Word's built-in heading styles and modify them, or manually format each heading

### Issue: Code blocks losing formatting
**Solution:** Use "Keep Text Only" when pasting, then apply Courier New font manually

### Issue: Tables/Figures not fitting
**Solution:** Resize or adjust margins for that specific page, or split content across pages
